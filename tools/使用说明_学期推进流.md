# 学期推进流工具使用说明

**主界面是打卡页**（各自文件夹的 `打卡_姓名.html`，本地浏览器打开）——看任务、打卡、生成周报都在那里。
本命令行工具只做三件事：**核验（check）／生成练习骨架（scaffold）／周报（report）**。

```
python tools/semester_flow.py check 周号 --deep            # 负责人：核验某周（在仓库根目录运行）
python tools/semester_flow.py report 周号                  # 负责人：生成周报 md

python tools/semester_flow.py --member 姓名 check 周号      # 成员：核验自己的练习（[FLOW] 契约）
python tools/semester_flow.py --member 姓名 scaffold 周号  # 成员：重新生成某周练习骨架
python tools/semester_flow.py --member 姓名 report 周号     # 成员：生成自己的周报
python tools/semester_flow.py --member 姓名 record 编号 pass "服务器实测值"   # 服务器跑通后补录
```

- 姓名＝宁显泷 / 衣思淼 / 代维斯丹 / 王散曼；负责人不加 `--member`。
- 进度文件：`learning/<姓名>/flow_state.json`（每人一份；删掉即重置）。
- 练习骨架已在 `learning/<姓名>/`；写完运行它输出 `[FLOW] ...`，`check` 按契约判定，不谎报。
- 服务器才能跑的练习（如 Vina 对接）：服务器实测后用 `record` 补录。
