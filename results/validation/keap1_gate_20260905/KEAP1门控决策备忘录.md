# KEAP1 多种子门控未过——决策备忘录（2026-09-05）

## 事实（全部留档于本目录）

1. **多种子门控（预注册政策：5种子独立起始、≥3/5 且中位 RMSD<2Å）**：
   - FXR/1OSH/FEX：0.72/0.75/0.77/0.85/0.91 Å，**5/5 过，中位 0.77** → PASS
   - KEAP1/4IQK/IQK：1.81/1.89 过，2.08/2.10/2.12 不过 → **2/5，中位 2.08** → FAIL（如实拦截）
2. **采样敏感性（exh=32，本目录 gate_sensitivity_exh32.json）**：各种子 RMSD 与 exh=16 几乎一致，仍 2/5、中位 2.08 → **不是采样不足，是协议本身的姿态恢复上限**。
3. **偏差模式（keap1_deviation_analysis.json，对称匹配近似分组）**：过门种子(123)磺酰胺锚点 ≤1Å 贴合；未过种子磺酰胺/甲氧基均值 ~1.9-2.3Å、最大 ~5Å——**含核心错位，非仅外围环翻转**。
4. 历史 1.10Å 是"错误化学+叠合 RMSD"双重口径 artifact（审计 F02/F07）；正确口径下该结构一直是 1.8-2.1Å 边界水平。

## 供全组决策的选项（开学后 W1-W2 议题，需队长+指导老师定）

| 选项 | 内容 | 代价/风险 |
|---|---|---|
| A. 换 KEAP1 共晶结构 | 另选配体更刚性/分辨率更高的 KEAP1 结构（如 4L7B、5FZN 等）重做门控 | 需重新核实结构背景与盒子；盒子口径变化需文档化 |
| B. 改判据并预注册 | 如"IQK 类柔性配体按 2.5Å 或叠合核对比"——须先书面预注册理由，不得事后凑过 | 有 p-hacking 观感，须导师签字认可 |
| C. FXR 单靶推进 | 双靶共识暂降为 FXR 单靶证据链（本诊断已跑通单靶管线） | 融合公式/报告口径都要改；失去 KEAP1 证据维 |
| D. 维持拦截 | KEAP1 不出生产对接，FXR 证据单独成链 | 最保守，最诚实 |

## 当前处置

生产对接对 KEAP1 **保持拦截**；本次已用 `--targets FXR_LBD` 跑通单靶诊断全链（制备/缓存/分榜/图表），产物全部标注"单靶诊断，不得当双靶共识结论"。
