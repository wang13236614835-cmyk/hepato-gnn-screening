## 拆项规则

| 维度 | 必须留下的内容 | 缺证与拒判 |
|---|---|---|
| 身份/来源 | 化合物ID、完整InChIKey/SMILES、盐型/立体化学、来源版本/原件SHA256 | UNKNOWN不记0分；手性未决不得混用确定异构体的活性或供货信息 |
| 直接活性 | target/species/isoform、assay/终点/单位、关系符、原数据及变换 | 不同靶点或assay不直接横排；混合预测pAct不冒充实验pIC50；截断值不当精确值 |
| 模型 | dataset/split/seed、训练日志、模型hash、同折baseline、接受标准、AD/UQ及当前资格 | 未合格或域外只登记探索假说；预测缺失≠阴性；不拿旧FASN/FXR资格授予新靶点 |
| 结构/ADMET | 受体/配体版本、制备/参数/原日志、PAINS与限制 | Vina和ADMET只提供计算支持；历史Vina单位先查原日志，本轮不猜填 |
| 靶点到疾病 | 直接结合/功能/细胞/动物/临床分层，激动或拮抗方向、疾病场景、反证 | 检索未见证据与实测阴性分开；靶点相关不等于该分子机制或疗效成立 |
| 可获得性 | 供应记录日期、结构对应、规格、lot/CoA与来源 | 历史目录不等于当前有货；药材来源不等于标准品；不自动采购 |

本轮各维度用SUPPORTED / CONTRADICTED / UNKNOWN / NOT_APPLICABLE及原文理由记录，不合成总分。若团队后续决定量化，须先签署版本、权重、校准样本、缺失处理和敏感性方案，再用新版本复算，保留旧输出；不能观察赢家后调权。
