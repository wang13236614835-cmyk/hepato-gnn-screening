## 当前统一路线

本轮非 HTML 文档统一按以下八步推进，顺序也是投稿前的证据链：

1. 暑假历史结果核验：保留原始输出，记录可复现项、差异和未核验项；
2. FXR 主线数据、结构和终点审核：先确认身份、来源、标签和终点能否支撑 MASH 问题；
3. GNN 与 RF/XGBoost/均值基线比较：同一数据、划分和指标下如实比较，允许无增益；
4. 随机划分与化学空间外推验证：分别报告随机划分、骨架/化学空间外推和泄漏审计；
5. 不确定性、校准、适用域和拒判分析：报告区间、校准质量、近邻范围和拒判规则；
6. CW-BCS 及天然产物应用分析：把排名作为计算优先级，补足药理证据和结论边界；
7. 独立复现和图表审阅：真人复算、独立脚本/引擎复跑、图表与数据逐项对账；
8. 论文写作、审稿问答和投稿：形成主稿、补充材料、回复模板和投稿包。

GNN 库只承担教学核验与 MOOC 打卡入口；AIDD 库承担 FXR/GNN/CW-BCS 论文主线。独立 THRB/FASN/SCD1、KEAP1 和其他探索属于分支，除非形成独立证据，不自动并入主论文。湿实验是后续可选路线，不是当前 16 周必做项。

GNN：暑假核验＋原16周学习打卡。AIDD：已立项FXR/GNN/CW-BCS论文的审核、模型比较、外推/校准、应用、复现和投稿。二者通过真实成果证据关联，不能混用模型成绩与候选榜。
