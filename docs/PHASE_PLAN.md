# 课题两阶段总规划（暑假 · 下学期）

> 定位：本文件是课题的**阶段划分总纲**。所有现有工作划入"第一阶段（暑假）"，
> 下学期工作以工作包（WP）形式组织在 `phase2_semester/`，每个工作包
> 含步骤、命令、期望输出与验收标准，供人工执行与核验。
> 每个文件的归属与核验方法见 `docs/MANIFEST.md`；
> 人工复现的操作细节见 `docs/VERIFY_MANUAL.md`。

## 一、阶段总览

| 维度 | 第一阶段（暑假 2026.7–8，六周） | 第二阶段（下学期 2026.9–2027.1，约16周） |
|---|---|---|
| 定位 | 流程搭建与小样本全链路跑通 | 上量、真实化、实验衔接与结题 |
| 计算环境 | 本地零依赖（纯numpy，笔记本可跑） | 服务器（RDKit / PyG / AutoDock Vina） |
| 数据规模 | 100 条（88 带标签 + 12 筛选池） | 目标 ≥1000 条带标签（数据库正式导出） |
| 对接 | 演示模式（物理启发打分占位） | 真实 Vina 对接，覆盖演示分 |
| 模型 | numpy 版 GNN + MC Dropout | PyG 版迁移 + 温度校准 + 回归升级 |
| 结点产出 | 协同评分排名 v1 + 中期报告 + 本阶段报告 | 排名 v2 + 结题报告 + 实验验证数据 |
