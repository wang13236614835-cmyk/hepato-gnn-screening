# 打卡验收规则（非HTML执行版）

1. 正式W1为2026-09-07—09-13，W16为12-21—12-27；开学前是预习。
2. 旧教学数字只对其源码/输入快照有效。完整记录版本、命令、数值与差异；修改后的代码无需复现错误历史值。
3. “≥1000条”“AUC不能下降”“ECE必须<0.10”不再是当前研究放行要求。数据质量、终点可比性、完整基线比较、区间及边界才是要求；样本不足与无增益如实报告。
4. 原45项、旧semester_flow检查只验证历史教学范围。固定常量测试仍可作为旧版练习，不能当V1投稿验收，也不能改数据迎合检查。正式论文用AIDD五人证据台账及真人复核，不把检查返回0当导师通过。
5. 老结果“✅完成”只代表相应计算记录；数据审核、科学验证和真人签核分开。对接恢复姿态不等于药效，来源药材不等于标准品可购。
6. 全线流程8步保留为教学线；FXR/GNN/CW-BCS论文在AIDD。独立V2、KEAP1不混入V1必做链。
7. W14—16保留写作、复现、问答活动，产物改为论文材料/审稿问答/可选后续评估，不预设结题答辩或湿实验完成。
8. MOOC已有9单元分布于W1—W14，不重复新建。实际标题、分钟、要点、教回、应用和同伴复核照原卡填写。
9. 保留原任务ID、存储键、备注、日志、导入导出；更新任务含义时旧完成不自动继承为新验收。此次没有读取/改动个人浏览器存储。
