## 一、全线研究流程（完整管线：`final-aidd-screening/`）

```
【步骤1 靶点档案】FXR(1OSH+FEX) + Keap1(4IQK+IQK)，证据四栏
      │  s1_target_profile.py → results/targets.json
      ▼
【步骤2 结构·口袋·redock门控】盒子=共晶配体包络+6Å；RMSD<2Å 才放行
      │  s2_prep_redock.py → docking/redock_gate.json
      │  ✅ 实测: FXR 0.74 Å / Keap1 1.10 Å（固定种子可精确重现）
      ▼
【步骤3 数据·建模】88 条标签(HP48正/DC40负) + 12 条NV池，5 条结构按 PubChem 校准
      │  scaffold 组级划分 58/13/17（53 个骨架组）
      │  基线: ECFP+RF(0.983) / Desc+LR(0.983)   ← 课程"基线先行"
      │  主模型: GCN+MC Dropout(AUC 0.95, ρ_方差-误差 0.676)
      │  适用域: 杠杆值 h*=0.362，NV 池 7/12 域外
      │  s3_model.py → results/metrics/model_summary.json
      ▼
【步骤4 漏斗】60 候选 → Lipinski/PAINS 预过滤(标记保留) → Vina 1.2.7 真实对接
      │  s4_dock.py → results/tables/docking_real_scores.csv
      │  ✅ 实测: 118/120 次(-10.41~-3.90)；小檗碱制备失败(季铵盐,已知局限)
      ▼
【步骤5 三源共识评分】final = 0.45×模型 + 0.35×真实对接 + 0.20×类药，域外×0.9
      │  s5_fuse_select.py → final_ranking_v2_real.csv（59 候选，黄芩苷 0.9601 居首）
      ▼
【步骤6 骨架多样性挑选】ECFP4 Butina 聚类 37 簇 → 每簇最优 → 多样性 Top-10
      │  → diverse_top10.csv（覆盖 8 个化学类别，体外验证默认名单）
      ▼
【步骤7-8 报告留档】REPORT.md + summary.json + 3 图
         run_all.py（全流程）/ run_all.py --model（快速复算）
```

## 四、质量要点（写报告/答辩可直接引用）

1. **数据管道用工业级工具校验**（RDKit 全量结构复验 + PubChem 权威结构校准留档）；
2. **结构证据以 redock 门控为前置**（RMSD<2Å 硬标准，双靶通过）；
3. **基线对照必须**（ECFP+RF 0.983 ≥ GNN 0.95：小样本阶段模型叙事重心在
   不确定性量化 ρ=0.676，而非点精度）；
4. **两证据源近乎独立**（模型-对接 Spearman 0.170），故三源共识评分必要。
