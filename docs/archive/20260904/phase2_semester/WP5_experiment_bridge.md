# WP5 文献深化与实验衔接（第9–16周）

主责：王散曼（化学信息与文献） | 核验人：代维斯丹
前置条件：WP2 排名 v2 出表

## 目标

1. 完成 literature/ 全部引用的人工原文核对（结题硬要求）；
2. Top 候选（尤其新分子松脂素、落叶松脂素）湿实验方案衔接；
3. 结题报告文献支撑章节。

## 步骤

1. 引用核对（在 literature/01 头部去掉"整理稿"声明的前提）：
   - 逐条检索原文（PubMed/CNKI），确认作者/期刊/年份与结论方向；
   - 每条回填"已核对✓+PMID/链接"；核对不了的条目删除或降级；
   - 抽查口径：A/B级条目100%核对，C级抽50%；
2. Top-10 机制深化：结合 WP2 真实对接的相互作用图（PyMOL出图），
   更新 literature/03 的机制映射与药效团结论；
3. 湿实验衔接方案（与导师确认后执行）：
   - 优先级：松脂素、落叶松脂素（模型+对接+域内三优，文献空白）；
   - 推荐体系：HepG2 细胞 CCl4/APAP 损伤模型，ALT/AST/ROS 三读数，
     设水飞蓟宾阳性对照、溶剂空白；
   - 产出：实验方案一页纸（进结题报告附录）；
4. 结题报告文献章节初稿。

## 期望输出

- literature/ 三份文档全部"已核对"状态；PMID 清单；
- 真实对接相互作用图集；实验方案一页纸。
