# GNN 库范围与当前状态

更新时间：2026-09-05。负责人：王启龙。

## 这个库应该放什么

GNN 库是暑假工作的收尾核验库，给组员使用。它负责：

- 原始 GNN/基线代码、历史输入表、可复现实验脚本和软件检查；
- 五位成员的原版周卡片、学习资源、任务分派、核验记录和导入/导出打卡；
- 对数据、结构、对接和代码的审计证据，以及明确标成历史的旧报告；
- 指向 AIDD 主库的入口和交接说明。

它不负责把旧 Top-10 直接变成药效结论。当前有效的状态入口是 `results/validation/software_checks.json`、`docs/audit/` 和本文件；旧的 `reports/midterm_report.md`、`reports/pdf_build/`、`reports/pdf_all/` 只保留作历史证据。

## 现在已经有的

- `tools/verify_research.py`：9 项软件/数据防回归检查；
- `tools/semester_flow.py`：保留原命令接口、学习验证卡、成员状态和周报命令；入口为下学期 16 周计划（第 1 周 09/07–09/13 起，2026-09-05 曾被压缩为两周收尾、当日已回滚）；
- 计划源：[PHASE_PLAN.md](PHASE_PLAN.md)、[VERIFY_TASKS.md](VERIFY_TASKS.md) 与各成员打卡页；MOOC 按复旦课程 12 章×16 周映射学习；
- `docs/audit/20260905/figure_text_alignment.md`：四张结果图与来源表、对象 ID、单位、版本的对照台账；
- 五个原版打卡页面：保留原标签页、原 `localStorage` key、确认勾选、日志、导入/导出；页面顶部增加当前复核口径；
- GCN 重复 dropout 梯度、RDKit 描述符、实际 SMILES/骨架、未审数据阻断、缓存失效和对接门控修复；
- 数据连接审计：原 100 条结构中发现 52 条连接不一致、43 条分子式不一致、4 条立体化学不一致；旧 Top-10 不能直接沿用；
- 独立起始构象重对接诊断：FXR 0.8507 Å 通过，KEAP1 2.0822 Å 未通过，因此没有发布新的批量排名。

## 现在明确没有、也不应假装有的

- 经过人工确认的 MASH assay-level 标签、终点定义和完整来源台账；
- 通过独立对接门控的全套受体/配体生产结果；
- 可交给实验人员的最终候选名单、实验 SOP、细胞/动物材料或湿实验结果；
- 指导老师批准记录、成员人工签名和任何“软件检查通过 = 科学结论成立”的证据。

所以 GNN 当前只能推进干研究核验和课程打卡。湿实验门槛由 AIDD 主库统一管理，未满足前不放行。

## 与之前版本的区别

| 项目 | 之前 | 当前修缮后 |
|---|---|---|
| 打卡页 | 曾被替换成简化的新页面 | 恢复原版 7 个标签页、原存储 key 和原导入/导出，再加顶部口径提示 |
| 旧指标 | AUC、RMSD、Top-10 容易被读成当前结论 | 旧数字保留作历史并标记待复核 |
| 数据 | 只看行数和旧排名 | 增加连接、分子式、立体化学和来源审计 |
| 对接 | 旧门控数字被当作已通过 | 独立复算分靶点报告；KEAP1 未过即停在诊断 |
| 研究边界 | GNN、湿实验和完整 AIDD 链混在一起 | GNN 做收尾核验；AIDD 做 MASH 主线；湿实验暂不放行 |
| 课程 | “看完就打勾” | 记录视频标题、时长、闭卷回忆和研究应用后再勾选 |

完整 MASH 证据链请进入 [AIDD 主库](https://github.com/wang13236614835-cmyk/aidd)；不要在本库另起一套候选排名。
