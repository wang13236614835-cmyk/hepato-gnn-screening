## 一、全线研究流程（当前权威版：`final-aidd-screening/`）

```
【步骤1 靶点档案】FXR(1OSH+FEX) + Keap1(4IQK+IQK)，证据四栏
      │  s1_target_profile.py → results/targets.json
      ▼
【步骤2 结构·口袋·redock门控】盒子=共晶配体包络+6Å；RMSD<2Å 才放行
      │  s2_prep_redock.py → docking/redock_gate.json
      │  ✅ 实测: FXR 0.74 Å / Keap1 1.10 Å（固定种子可精确重现）
      ▼
【步骤3 数据·建模】88 条标签(HP48正/DC40负) + 12 条NV池
      │  scaffold 组级划分 58/13/17（53 个骨架组）
      │  基线: ECFP+RF(0.983) / Desc+LR(0.983)   ← 课程"基线先行"
      │  主模型: GCN+MC Dropout(AUC 0.95, ρ_var-err 0.676)
      │  适用域: 杠杆值 h*=0.362，NV 池 7/12 域外
      │  s3_model.py → results/metrics/model_summary.json
      ▼
【步骤4 漏斗】60 候选 → Lipinski/PAINS 预过滤(标记) → 真实 Vina 1.2.7 对接
      │  s4_dock.py → docking_real_scores.csv
      │  ✅ 实测: 118/120 次(-10.41~-3.90)，小檗碱制备失败(季铵盐,已知局限)
      ▼
【步骤5 共识评分】final = 0.45×模型 + 0.35×真实对接 + 0.20×类药，域外×0.9
      │  s5_fuse_select.py → final_ranking_v2_real.csv（59 候选）
      ▼
【步骤6 多样性挑选】ECFP4 Butina 聚类 37 簇 → 每簇最优 → 多样性 Top-10
      │  → diverse_top10.csv（覆盖 8 个化学类别）
      ▼
【步骤7-8 报告留档】REPORT.md + summary.json + 3 图，一键复现
         run_all.py（全流程）/ run_all.py --model（快速复算）
```

**排名版本链**：v1（演示分，`results/rankings/final_ranking.csv`，保留作对照）
→ **v2（真实分，`final-aidd-screening/results/tables/final_ranking_v2_real.csv`）**。
重大变化：丹参酮IIA #48→#11、芹菜素 #17→#4、水飞蓟宾 #7→#30。

### E. 教训沉淀（课程"数据挑战"的活案例）

1. 暑假纯 Python SMILES 解析器过松，放行了 5 条化学无效结构 → 教训：
   **数据管道必须用工业级工具校验**（RDKit），"能跑通"≠"化学正确"；
2. 演示分与真实分相关性低（替换后排名大变）→ 教训：**占位分数只可用于流程联调，
   任何对外汇报不得引用**（与导师汇报口径一致）；
3. 基线反超深度模型（0.983 vs 0.95）→ 教训：小样本阶段**模型叙事重心应放在
   不确定性量化**（ρ=0.676）而非点精度。
