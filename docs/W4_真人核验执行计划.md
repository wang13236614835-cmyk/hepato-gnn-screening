## Git 真人核验规则

Git 作为真人操作留痕层，但 Git 本身不自动放行 AIDD Gate。

每条核验必须有：

1. 主核人亲自打开原始数据库、原始论文或专利；
2. 一份独立结果文件；
3. 主核人自己的 Git 提交；
4. 一名交叉复核人检查原始来源和表述边界；
5. 负责人只检查流程和合并，不替组员填写判定；
6. 只有通过 Workbench/AIDD 受控导入后，才计入正式 real_human_review_completed。

禁止 AI 代写 VERIFIED / CORRECTED / REJECTED，也禁止只看 AI 摘要、不打开原始来源。
