## 历史快照与当前放行边界

旧 AUC/ECE、旧 Top-10、`verify.py` 的 45 项、旧双靶结果以及曾写入的 1000 条数据目标，均是对应版本的教学或审计快照。它们只用于解释差异、复现历史版本和定位回归，不能作为当前论文放行条件；新旧结果不同不通过改数据来“对齐”。无增益、样本不足、外部验证失败和结构门控失败都可以作为真实结果进入讨论。软件通过、数据审核、科学验证、真人复核和导师放行分开记录，排名只表示计算优先级，不等于药效或机制证实。

当前统一路线为：历史结果核验 → FXR 主线数据、结构和终点审核 → GNN 与 RF/XGBoost/均值基线比较 → 随机划分与化学空间外推验证 → 不确定性、校准、适用域和拒判分析 → CW-BCS 及天然产物应用分析 → 独立复现和图表审阅 → 论文写作、审稿问答和投稿。12 月后只做投稿、返修和归档，不新增第 17 周学习任务。
