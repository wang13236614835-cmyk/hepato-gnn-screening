# 文件使用指南——仓库里的文件是什么、怎么查、推荐方法、注意事项

> 给组员的速查表：打卡页和任务里引用的每个文件，在这里都能查到"它是什么、怎么打开、
> 推荐怎么用、有什么坑"。更新时间 2026-09-05；行数/内容以仓库当前版本为准。

## 一、总纲文档（docs/）

| 文件 | 是什么 | 怎么查 | 推荐方法 | 注意 |
|---|---|---|---|---|
| docs/PHASE_PLAN.md | 两阶段总规划：暑假做了什么、下学期 WP1–WP5 怎么分 | 本地 md 阅读器或 GitHub 页面 | 先读"阶段总览"和"成员分工"两节 | 周程口径：第1周=09/07–09/13，打卡页同源 |
| docs/VERIFY_TASKS.md | **人工校验任务分派表**：谁核哪条线、时限、预期值 | 打开按自己小节逐条做 | 预期值只引用存档基线，不凭记忆填 | N3/L5 的"45项"是旧工作库口径（审计F11）；完成要签名 |
| docs/VERIFY_MANUAL.md | 核验手册 §0–§5：每条任务的具体命令与操作步骤 | 对照 VERIFY_TASKS 的编号翻对应小节 | 照命令逐条复制执行，输出贴回记录表 | 命令要在仓库根目录跑；别跳步 |
| docs/MANIFEST.md | 全文件中文备注清单：每个文件是什么+谁弄的 | 搜文件名定位 | 改动公用文件后检查是否需登记 | 只读参考，不在此提交任务 |
| docs/MEMBER_WORKBENCH.md | 全员工作台导航（按人分节） | 找自己名字那节 | 入口聚合页，具体任务回 VERIFY_TASKS | 与各人文件夹工作台.md 内容同源 |
| docs/PROJECT_STATUS.md | 当前研究状态与判定（审计后口径） | 直接读表 | 引用结论前先看这张表 | "可复现≠数据正确"；机器工作不计人工完成 |
| docs/REPO_SCOPE.md | 本库边界：放什么、不放什么、现在有什么/没什么 | 直接读 | 新增文件前先对边界 | 不在本库另起候选排名 |
| docs/文件使用指南.md | 本文件 | — | — | 引用处更新时同步本表 |

| 文件 | 是什么 | 怎么查 | 推荐方法 | 注意 |

| data/curation/compound_registry.csv | **身份主表**：100条 名称→CID→InChIKey→建议结构 | Excel/文本打开，按 compound_id 查 | 一切结构相关工作的唯一入口 | identity_status=pending_review，人工复核前不放行；DC-030 有标签反例注记 |

| results/rankings/final_ranking.csv | 旧 Top-60 排名（演示→真实版过渡） | 打开看 rank/final_score 列 | 只作历史核对 | **旧榜口径**：榜首黄芩苷结构身份待复核（F01），不引用为新结论 |
| results/metrics/ | 指标与预测输出 | 对照 model_summary.json | AUC 看区间不只看点值 | 旧 AUC 待重算；新口径带 95% 自助区间 |
| results/validation/ | 软件检查与修复验证证据（fixes_verification 等） | 读 JSON 里 checks 各项 | 引用验证结论的原始出处 | "通过=机器可核验项生效"，不等于科学验收 |
| docs/audit/20260905/ | **F01–F20 审计报告与证据**（唯一采信的 AI 产出） | 先读报告 md，再按编号查证据文件 | 修复/答辩引用问题的第一来源 | 引用别越界（未做118次独立重跑等边界见报告§1） |

## 四、工具与学习（tools/ learning/）
