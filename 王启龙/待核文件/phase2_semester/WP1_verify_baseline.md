# WP1 复现核验与基线固化（第1–2周）

主责：王启龙（工程） | 核验人：全员（各自模块）
前置条件：无（本地即可）

## 目标

开学第一件事：证明暑假结果在每个人手上都能复现，把暑假基线固化成
"不可再改动"的 v1.0 标签，之后所有第二阶段改动都有对照基准。

## 步骤

1. 全员各自按 `docs/VERIFY_MANUAL.md` §0–§2 走一遍（约10分钟），
   在手册末尾核验记录表签名；
2. 各模块负责人完成自己模块的 §3 深度核验：
   - 宁显泷：§3.1 解析器用例 + 抽查 gnn.py 超参与文档一致性；
   - 衣思淼：§3.4 数据抽查 + §3.5 排名手工验算；
   - 代维斯丹：§3.3 指纹确定性 + 4张图与CSV对照；
   - 王散曼：§3.4 证据溯源抽查5条（lit/01回填"已核对"）；
   - 王启龙：汇总核验记录，`python reports/pdf_build/verify.py` 输出
     "通过45项；不符0项"截图存档 `results/logs/`（新建）；
3. 打标签固化基线：

```bash
git tag -a v1.0-summer -m "暑假阶段基线：60候选排名v1+45项校验全过"
git push origin v1.0-summer   # 若有远端；无远端则本地标签即生效
```

## 期望输出

- 核验记录表5行签名；verify.py 通过截图；
- git 标签 v1.0-summer。
