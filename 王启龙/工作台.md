## 怎么操作（五步）

1. **拿仓库**：`git clone https://github.com/wang13236614835-cmyk/hepato-gnn-screening.git`（或 GitHub 页面 Code → Download ZIP）；
2. **先读本文件＋打卡页**：本文件夹 打卡_王启龙.html（首屏"🧭 我的工作台"）；
3. **动手核验**：按上表逐条执行，预期值以 docs/VERIFY_MANUAL.md 为准；
   `python run_all.py`；`python reports/pdf_build/verify.py`（45 项截图存 results/logs/）；
   `python tools/semester_flow.py check 1 --deep`；
4. **记录**：在下表签名；问题记 docs/VERIFY_TASKS.md §5（A 级先停线报告）；
5. **每周**：打卡_王启龙.html 按周打卡、周五生成周报发导师、周日 git push。
